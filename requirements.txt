# Forecasting + CPI projection — single source of truth lives in the
# Census Forecaster package (extracted from this repo). All ACS forecast
# logic, BLS CPI projection, walk-forward backtest harnesses, MOE
# propagation, multi-source anchors, and hidden-data calibration are
# imported from there. Use a git pin (or `pip install -e
# /path/to/Census-Forecaster` for local development).
#
# Census-Forecaster is a uv workspace: the repo root has no build backend,
# so each package must be installed from its own subdirectory. census-common
# is listed first because census-forecaster depends on it by name — pip needs
# the direct URL on hand to resolve that dependency.
#
# Pinned to a commit hash (not @main) so upstream changes can't break this
# repo's install between syncs. To bump: update both hashes to the same
# upstream commit and re-run `pip install -r requirements.txt` + pytest.
#
# NOTE: census-forecaster's pyproject force-includes src/census_forecaster/data
# on top of the package include, so hatchling >= 1.26 refuses to build the
# wheel ("A second file is being added to the wheel archive at the same
# path"). Until that force-include is removed upstream, install with
#   PIP_CONSTRAINT=build-constraints.txt pip install -r requirements.txt
# which pins hatchling < 1.26 inside the isolated build env (the CI workflow
# already does this).
